The flow

Lobby to payout

  1. Create or join

    Start a lobby from a game template and choose the entry fee within its minimum, maximum and step — or join an open lobby.

  2. Invite players

    Invitations go by email to your friends, referrals and other players — up to about 10 people.

  3. Game starts

    As soon as enough players have joined, the game starts and everyone gets the same starting balance.

  4. Winner paid

    Checks run every second. At the end time the game is ranked and the winner is paid the pot minus commission.

Trading Duel · 1 vs 1

Two traders. One pot.

Fast, personal competition. You set the stake, the second player joins, and the game starts at once. It runs for a fixed time — minutes, hours or days.

  • Loss limit % — reaching it eliminates that player.
  • Optional profit target % — with "first to target" on, the first player to reach it wins at once and the game ends. Otherwise it's checked at the end.
  • Winner order — reached the target first, then higher profit %, then whoever reached the target earlier.

Every way a duel can end

A winnerTakes the pot minus the platform commission.
One eliminatedThe other player wins — but only if they meet the target.
DrawExactly equal profit and neither reached the target: both are refunded, minus the commission.
No winnerNobody meets the target: the platform keeps the fees.
Both eliminatedThe platform keeps the pot.

The Duel is the only Adiox product with a draw outcome.

Trading Battle · 3+ players

Winner takes all.

The same as a Duel, for three or more players. The game starts when the chosen number of seats is full, and only first place is paid.

  • Ranking — reached the target, then profit %, then the smallest loss %, then the earliest time the target was reached.
  • No draws — if nobody meets the target there is no winner.

Lobby rules

Fair for everyone waiting

24-hour expiry

A lobby waiting more than 24 hours expires and every player is refunded.

Creator cancels

Only the creator can cancel a lobby, and only before the game starts.

Set by template

Each template fixes the player count, fee range, starting balance, leverage, commission, target, loss limit, allowed symbols and duration.

FAQ

Game questions

Where can I compete against my friends in a simulated forex trading game?

On Adiox, create a Trading Duel (1 vs 1) or a Trading Battle (3 or more players). Invitations go to your friends and referrals first. Everyone trades the same starting balance on a virtual-money account for a fixed time, and the winner takes the pot minus commission.

Who sets the entry fee?

The player who creates the lobby, within the template's minimum, maximum and step. Everyone who joins pays the same fee.

What does the platform commission cover?

The commission percentage is set on each game template and is deducted from the pot before the winner is paid, and from refunds in a Duel draw.

What if nobody reaches the profit target?

When a game has a target and nobody meets it, there is no winner and the platform keeps the fees. Check whether a template has a target before you join.

Where are finished games recorded?

On the game leaderboard, which lists completed Duels and Battles with the winner, the prize and the commission. Leaderboards →
